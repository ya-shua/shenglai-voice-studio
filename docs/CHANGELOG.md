# 声来（voice-studio）更新日志

> 一句话，一个声音，一首歌。
> 所有版本均为纯云端 Key 驱动，不做本地模型部署；密钥只存本机 `config.json`。

格式参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

> 注：git tag 只打了部分版本（v1.3.x / v1.4.x / v1.7.0 起）；1.5.0–1.6.0 的改动随 **v1.7.0** 一并发布，未单独打 tag。本日志按开发版本号完整记录。

---

## [1.8.1] - 2026-11-07

### 新增（tide 心情引擎联动）
- **`/api/speak`、`/api/tts`、MCP `voice_tts`、面板情绪下拉** 全部支持 `mood=tide`：语速/音调/语气全部跟随 tide 心情引擎的实时情绪（七情账户+小标签+强度，比固定情绪词更细腻）；tide 不可用时安全降级
- tide 语气描述（instruct）作为 style 传给 MiMo（chat 式引擎原生吃语气），情绪表现力最强
- 文档：`docs/情绪联动.md`（三种插件形态的对接指南）

### 隐私
- `lib/ring_ingest.py` 移除本机路径中的 QQ 目录名——改为**通配扫描**（`D:/AI/*/SnowLuma/node.exe` + 环境变量 + PATH），本机功能不受影响，仓库无隐私字样

### 运维
- 收录 `scripts/push_by_api.py`（github.com:443 被墙时的 API 推送脚本，PAT 路径走参数不进仓库）

## [1.8.0] - 2026-11-07

### 新增（海螺 MiniMax 接入完善）
- **MiniMax verify_key（零成本探活）**：坏模型名打一次鉴权，`base_resp.status_code=1004` → 友好"Key 无效"指引（注意字段是 status_code 不是 status，实测纠正）
- **MiniMax 原生情绪**：t2a_v2 `voice_setting.emotion`（开心/兴奋→happy、生气→angry、难过/委屈→sad，emotion_scale 1.3）+ 音调/音量参数接入（pitch 折半音、vol 按 50=1.0 折算）——情绪链路在 MiniMax 上是真原生情绪
- 说明：qq-bridge 已由用户删除弃用，QQ 侧接入待定；声来侧 /api/speak（含 emotion）等接口全部就绪，任何新框架拉取即用

### 新增（QQ 语音落地：接进本机 QQ 机器人链路）
- **qq-bridge 接入**（适配器在 qq-bridge 侧，声来本体零代码改动）：DeepSeek 角色在 QQ 里用 `qq_speak` 工具把文字实时合成语音条发出——`声来 /api/speak → 临时 wav → record 段 → SnowLuma 转 SILK → QQ`，get_msg 回读验证落地
- 实测通过：dryRun 门禁全过 → 真发主人号（「测试御姐」，15 秒语音，verified=true）
- **角色 → 音色绑定**：qq-bridge 侧 `roleVoices` 配置，音色解析顺序 显式指定 > 角色绑定 > 面板当前音色；女儿模式绑定 MiMo 免费造的「小鲸鱼」音色，实测 verified=true 来源=role
- **「当前音色」成为 TTS 输出默认**：`/api/speak` 不带 voice 参数时用面板当前音色；`POST /api/voices/current` 设置；大厅「用她说话」/顶栏切换自动同步——挑中的音色即刻成为对外输出音色（bridge 全局默认留空即跟随）
- **修复：大厅聚合写死供应商名单**——`hall_voices` 硬编码 4 家 id，MiniMax（海螺）虽然适配器早就带目录能力（9 个预置音色），却一直进不了大厅；改为**能力驱动动态聚合**（含自定义适配器）：谁声明 `catalog` 谁自动上大厅，以后新增模型零改动同步出现。MiniMax 未接 Key 时显示「待接入」，接入后即点即听（官方无公开样音直链，免费试听需要 Key）
- **注册表写入加固**：`save_registry` 改为原子写（tmp + os.replace）+ 每次保存前留 `.bak`、读取失败自动回退备份。（起因是一次误判：把用户主动删除音色当成了并发覆盖"事故"并错误恢复了数据——已按用户意图改回；加固本身保留，防未来的并发写损坏）
- 文档：`docs/环形的心对接.md` 更新为两条链路（主链路 qq-bridge + 备选云端 AstrBot）

### 新增（跨平台复刻：跨模型输出）
- **`POST /api/cross-clone`**：拿 A 平台音色的样音素材 → 克隆到 B 平台 → 正式登记成新音色。素材来源按优先：官方样音直链（百炼 94 个/硅基 8 个）→ 试听缓存 → MiMo 内置音色现场免费合成一段。目标平台两种克隆形态都支持：MiMo 直传式（`clone` 能力，素材落素材库、音色条目 `mimo-ref:` 指向参考文件）与注册式（bailian/siliconflow 等走 quick_clone keep）
- **实测打通**：龙婉（百炼官方样音 144KB）→ 复刻到 MiMo（免费）→ 登记为「龙婉·小米 MiMo TTS」→ `/api/speak?voice=龙婉·小米 MiMo TTS&emotion=温柔` 跨模型合成 ✓
- **大厅 UI**：选中音色后预览栏出现「目标平台 ▼ + 跨平台复刻 →」（仅列出有克隆能力且 Key 就绪的平台；克隆形态 enroll/clone 双支持）；源平台和目标相同则不出
- **MiMo 适配器增强**：`mimo-ref:` 音色复用参考素材合成；MiniMax 原生情绪字段（前一轮）

### 新增（情绪联动 + Key 归属说明）
- **情绪接口（情绪插件联动入口）**：`/api/speak`、`/api/tts` 新增 `emotion` 参数（开心/兴奋/温柔/生气/委屈/难过/撒娇/困倦/得意）——声来折算成语速/音调/音量增益，MiMo 音色额外带原生语气词（"语气生气，硬邦邦的"）；面板「合成正式版」加情绪下拉；未知情绪自动跳过不会炸。情绪插件/AI 只需把当前心情一个词传进来
- **Key 归属全说明白**：大厅页首行直接写清"发语音用该音色所属模型的 Key"；选中音色时来源行显示"· Key ✅ 合成可用 / ❌ 失效 / 未接入"；造声音三个入口各自标注用哪个 Key（描述生成=MiMo 免费 / 克隆=看来源 / 登记已有=不需要）；翻唱指南补**免费路线**（挑音色→Seed-VC 直接翻唱，无需素材训练无需 Key）与素材补全路径

### 免费音色页（UI 手感）

- **导航重排改名**：我的音色（置顶）→ 免费音色 → **自由造音**（原"造声音"）→ 翻唱 → 模型接入；相关文案同步

- **「用她说话」当场说清发语音行不行**：试听（官方样音**录音**，免费）≠ 发语音（**实时合成**，要 Key）——登记百炼等音色时立刻警告"发语音需要 X Key（当前失效/未接入），想免费发语音选 MiMo 音色"，不再让人用了才发现；页首说明同步改写并点破"声音是各家的资产，MiMo 的 Key 只能发 MiMo 的音色"
- **Key 失效全链路可感知**：新增 `verify_key` 能力（零成本探活）+ `POST /api/verify-key`——「模型接入」页每家已配置的模型加**「测试」按钮**，贴完 Key 一点即知行不行；百炼 401 错误翻译成一句人话（"Key 无效或已过期，去模型接入页重贴"）；大厅对 Key 失效的模型如实显示「⚠️ Key 失效」徽标（不再假装可试听、点了才报英文 401），点卡守卫同步跳过失效模型
- **翻唱页重排版**：状态检查改胶囊一行、表单按工作流重排（歌手音色→引擎/模式→文件→高级参数→全宽开始按钮）、「怎么得到歌手音色」折叠成可展开行；修「引擎/歌手音色」错位（label 里换行按钮撑高列）
- **说话页并入免费音色**（侧边栏六页 → 五页）：语速/音调/音量/格式调参 + 「▶ 合成正式版」+ 我的音频（原产出记录）全部搬进大厅——挑声音和用声音不再分家。正式合成用顶栏「当前音色」，克隆音色照常可用，Ctrl+Enter 快速合成
- **我的音频显示上限**：超过 20 条自动变固定高度滚轮（不再无限撑长页面）
- **试听进度条搬进顶部预览栏**（风格筛选旁边，随栏吸顶）——不用再滚到底部找播放进度
- **试听文字框加大为双行**（可拖高），长句子不再憋在一行里
- **点音色卡即自动试听**：直接用输入框里的文字合成/回放（命中缓存秒开）；未接入且无样音的卡片只选中、不弹接入引导；快速连点只播最后一次（过期请求丢弃）
- **修复：阿里官方样音外链试听 404（Format error）**——播放器缓存戳 `&t=` 拼到了无查询参数的外链上（`xxx.mp3&t=123` 是非法 URL，阿里返回 404 XML）；现在外链原样播放，缓存戳只拼内部链接。触发路径：输入**没缓存过的新文字**点百炼音色（默认文字都被预热缓存过，所以平时好好的，一输新文字就炸）
