格式参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [1.3.0] - 2026-11-02

- **筛选拆成「性别」+「风格」两个维度**：顶部原来的「分类」下拉（性别、风格、语言混在一起）改为「性别」（全部/女声/男声）

## [1.2.9] - 2026-11-02

### 修复（「面板已更新」横幅常驻、点刷新也不消失）
- 根因：`panel/www/app.js` 里 `CLIENT_VERSION` 手写成 `"1.2.6"`，而服务端 `config.VERSION` 是 `1.2.8`——两者永远不等，横幅就永远显示，`location.reload()` 重载后依旧出现，看起来像"点刷新没反应"
- 改法：版本号只保留 `lib/config.py` 一处，`server.py` 渲染首页时注入 `window.__APP_VERSION__`，前端据此判断自己是否旧版；横幅只在前端 JS 版本真的落后于服务端时出现
- 附带：前端读不到注入值（如直接开了旧缓存页）时不弹横幅，避免误报

## [1.2.2] - 2026-11-02

### 修复（重大根因）
- **绑定中断总根因**：wire() 中残留旧版页面的元素绑定（#bl-save 等），这些元素在历次重构中消失——`null.addEventListener` 抛 TypeError 使 **wire 中途崩掉，其后所有按钮（大厅试听/合成/翻唱等）自 1.0.4 起从未绑上**。这是"点了没反应"的总根源。
  - wire() 整体重写：全部改用空值安全的 `on()` 绑定，单个元素缺失不再中断
  - 三大关键按钮（大厅试听/合成/造声音）增加 **document 级事件委托兜底** + 异常 toast 上报

### 变更
- **面板全面重排为侧边栏布局**：左侧六项导航（🎧音色大厅(默认) / 🗣️说话 / ✨造声音 / 🗂️我的音色 / 🎵翻唱 / ⚙️模型接入），每页一句职责说明；音色大厅恢复独立页并成为默认首页；删除冗余的 A/B 对比组件
