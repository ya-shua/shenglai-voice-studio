# 素材采集与音色获取指南

## 零素材的最快路径：声音大厅 🎧

面板「**大厅**」页聚合了 25+ 官方免费音色（小米 MiMo / 百炼 / 硅基流动，接入后自动扩展），按分类筛选（温柔型 / 活力型 / 沉稳型 / 播报 / 双语…），在线试听、一键「用她说话」登记——不想造音色时先去大厅挑一个。

## 你的主要方式：模型生成（无需录音）

### 方式一：AI 直接生成音色（零素材，最快）✨

右上「**＋新建音色**」→「**✨ 凭空造一个**」：一句话描述想要的声音 → 模型直接生成专属音色，连试听都帮你做好，并自动设为当前音色。

- 描述模板：**性别 + 年龄 + 音色质感 + 语气 + 语速**，例："年轻女性，声音清亮干净，语气自信从容，语速适中偏快"
- 需要：设置里填 Workspace ID（声音设计走 v3/v3.5 模型）
- 生成的音色与模型绑定，合成时选同一模型

### 方式二：模型生成素材（官方音色朗读 → 存素材）🧬

「**🧬 素材**」页 →「**⚡ 一键补 3 条**」：挑一个官方/已有音色读三段口播稿，直接存为当前音色的素材（也可写自定义文本单条生成）。

- 生成的音频**干净无噪**，天然满足克隆要求
- 每条 50~80 字 ≈ 15~20 秒（克隆要求 ≥10 秒），三条约 45 秒
- 文本写口语化短句，避开生僻字和易混数字

### 方式三：AI 链式生成

用 A 音色生成素材 → 克隆出 B 音色 → 再用 B 生成新素材。注意：链式克隆会有轻微音色漂移，建议以官方音色或真实素材为"锚"，别链太多层。

## 录音素材（备选路线）

> 安静房间，手机贴近嘴边，连续清晰说（或唱）**10~20 秒**，导出 **WAV/MP3**（≥16kHz）——无伴奏、无混响、无他人声。

## 硬性要求（克隆用，模型生成的素材天然满足）

| 项目 | 要求 |
|---|---|
| 时长 | 10~20 秒最佳，最长 60 秒（Fish 15 秒起） |
| 格式 | WAV（16-bit）/ MP3 / M4A |
| 大小 | ≤10MB（百炼）/ ≤20MB（Fish） |
| 采样率 | ≥16kHz |
| 内容 | 至少 5 秒连续清晰语音，停顿不超过 2 秒 |
| 禁止 | 背景音乐、环境噪音、混响、多人说话 |

声音复刻（百炼）免费；Fish 复刻走网页端；语音合成按字符计费。

## 唱歌素材（翻唱线用）

- 在 kits.ai 网页端用**多段唱歌素材**（干净干声 ≥10 分钟最稳）训练歌手音色模型
- 干声（无伴奏清唱）最理想；带伴奏的版本也可（工作台会先做伴奏分离）
- 模型生成的素材是"说话"不是"唱歌"，唱歌音色仍需真人素材
- 直播/视频切片先剪掉说话杂质、笑声、杂音

## 入库方式

- 模型生成：素材页一键入库
- 本地文件：素材页拖拽上传，或把路径告诉 AI 助手（voice_material_add）
