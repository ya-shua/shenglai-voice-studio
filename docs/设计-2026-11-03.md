## 一、产品定位与用户动线

**声来不是"一个 TTS 面板"**，而是 AI 角色的声音引擎：

```
环形的心（记忆库）──► 她知道自己是谁
声来（语音工作台）──► 她能开口说话、唱歌
SnowLuma ⇄ qq-bridge ──► 她的嘴（QQ 语音，qq_speak → /api/speak，2026-11-04 实测）
```

用户动线（五页侧边栏，2026-11-04 由六页合并而来：说话页并入免费音色。每个目标全站只有一个入口）：

| 页 | 用户目标 | 关键动作 |
|---|---|---|
| 🎧 免费音色（默认首页） | 挑声音 + 用声音 | 111 个官方音色，选模型→筛选→**自定义文字试听**（点卡即听）→ 调参「合成正式版」出文件 → 我的音频（超 20 条变滚轮） |
| ✨ 造声音 | 造专属音色 | ✨描述生成（MiMo/百炼）/ 🎙️音频克隆（全模型通用）/ 📚登记已有 |
| 🗂️ 我的音色 | 管理与补素材 | 音色库 + AI 一键补 3 条素材 + 一键注册 |
| 🎵 翻唱 | 整曲换声 | 分离 → 只换人声 → 混回伴奏 |
| ⚙️ 模型接入 | 接模型 | DS 式行列表 + ＋添加模型双页签 |

**设计铁律：每个用户目标全站只有一个入口。** 曾经"获得声音"散在 4 处、"试听"散在 3 处，被用户点名"功能东丢西落的"——1.2.0 信息架构重构确立本铁律。

## 二、总体架构

```
┌─ ZCode 插件层 ────────────────────────────────┐
│ MCP 服务器（stdio，16 工具）                     │ ← AI 对话驱动
│ 斜杠命令 /voice:panel /voice:tts /voice:enroll │
│ 技能 SKILL.md（AI 行为手册）                     │
├─ 面板层（pythonw 常驻 127.0.0.1:17878）────────┤
│ 六页工作台 + 对外 HTTP API：                    │
│   GET /api/speak?voice=&text=   ← 音频字节直出  │ ← 任何框架拉取即用
│   GET /api/speak/voices         ← 音色列表      │
│   /api/hall /api/preview /api/preview-cache    │
│   /api/warm-previews /api/clone-universal …    │
├─ 业务层 lib/flows.py ─────────────────────────┤
│ 注册/快速克隆/通用克隆/设计/合成/素材/预热/翻唱    │
├─ 供应商适配层 lib/providers/（capability 声明式）─┤
│ mimo / bailian / siliconflow / minimax /       │
│ elevenlabs / fish / kits / local-svc / custom  │
├─ 支撑层 ──────────────────────────────────────┤
│ preview_store（试听缓存） audiomix（混音）        │
│ preview_audio（官方样音导入）                     │
└──────────────────────────────────────────────┘
数据根目录 D:\AI\声音工坊\（VOICE_STUDIO_HOME 可覆盖）
```

**设计原则**：
1. **纯云端**：不做本地模型部署（local-svc 的 Seed-VC 例外，它是免费翻唱刚需；ffmpeg 只算文件工具）
2. **capability 声明式**：每个适配器声明 `capabilities`（tts/enroll/design/catalog/convert…），业务层按能力路由，不按厂商硬编码
3. **两边本体都不改**：与环形的心/AstrBot 的对接只靠 HTTP 接口 + 薄适配器（照 integrations/astrbot 的"搬运工"哲学）

## 四、关键机制设计

### 4.1 试听三层保障（免费音色页的核心）

**层 1：官方样音直连（零 Key 零合成）**
- 阿里：官方音色列表页解析「voice → 试听 mp3」映射（101 条，去情绪噪音行后 94 个），24h 缓存 + 接口失败自动回退
- 硅基：官方文档 OSS 样音按命名规则直拼（`fish_audio-音色名.mp3`）
- 未接入的模型：试听直接回放官方样音——**不弹接入引导**（`free_preview` 直通）

**层 2：试听缓存 preview_store（MiMo 等需合成的音色）**
- key = provider + voice_id + text 的 md5；同一音色+文字只合成一次
- 扩展名通配查询（mp3/wav 都能命中——MiMo 返回 mp3、百炼返回 wav）
- 大厅加载时自动预热当前模型全部音色（后台线程，不阻塞页面）

**层 3：接入引导（ensureProvider）**
- 未接入且无样音 → 弹只含该模型字段的接入引导，保存后无缝继续原操作

### 4.2 对外语音接口（框架无关）

```
GET /api/speak?voice=音色名&text=文字&rate=1.0   → 音频字节直出
GET /api/speak/voices                            → 音色列表 JSON
```

qq-bridge（QQ 机器人桥，2026-11-04 实测）/ 环形的心 / AstrBot / 任何框架拉取即发，无需碰面板。这是"声来作为 AI 角色声音引擎"的正式接口。

### 4.3 稳定翻唱流水线

```
歌曲 ─► 人声/伴奏分离 ─► 只对人声换声 ─► 混回伴奏 ─► 成品
```

- 伴奏全程不动——稳定关键
- 双引擎：本地 Seed-VC + demucs（免费）/ Kits.AI（订阅）
- 混音器：纯标准库 wav 直混，ffmpeg 可用时任意格式

### 4.4 安全绑定（前端永不静默失效）

**教训**：1.0.4 设置页重构删了旧元素，但 wire() 还在给它们绑事件——`null.addEventListener` 让 **wire 中途崩掉，其后十几个按钮从那天起全是死的**（用户多轮"点了没反应"的总根因）。

修复三重保险：
1. wire() 全部改用空值安全绑定 `on(sel, ev, fn)`（元素不存在只跳过自己）
2. 三大核心按钮（大厅试听/合成/造声音）加 **document 级事件委托兜底**
3. 委托内 try/catch + toast 上报，异常永不再静默

### 4.5 缓存戳（JS 永远最新）

**教训**：固定版本号缓存串会命中浏览器旧缓存（用户多轮"改了没生效"）。

最终方案：`app.js?v=md5(app.js 内容)` —— 文件一变 URL 必变，且 index.html 每次请求动态注入。

### 4.6 版本横幅

前端 `window.__APP_VERSION__`（服务端注入 config.VERSION）与自身 `CLIENT_VERSION` 比对——不一致自动出现「点击刷新启用新版本」横幅。版本号只在 `lib/config.py` 一处维护。

## 五、前端信息架构

侧边栏六页（860px 以下自动折叠为顶栏），每页一句职责说明，当前音色贯穿说话/素材/翻唱。

**防错设计**：
- 顶栏音色下拉空态隐藏、按钮「开始创建 ↔ ＋新建音色」随状态切换
- 各页空态给指路卡（"还没有音色——先去发现/造声音"）+ 直达按钮
- 删除用**两段确认按钮**（第一次变红"确认删除?"，3 秒未点自动复原）——不依赖原生 confirm（内嵌浏览器沙箱会吞弹窗）

## 七、安全与隐私

- API Key 只存本机 `config.json`，面板显示脱敏（`sk-1****abcd`），前端占位符提示"留空则不修改"
- 对外接口只监听 127.0.0.1
- git pre-push 隐私门禁：拦截 `sk-`/`ghp_`/邮箱/手机号（本仓库 hooks/pre-push）
- 原则：**不做本地模型部署**（Seed-VC/ffmpeg 例外：前者是免费翻唱刚需，后者是文件工具）

## 八、踩过的坑（重要，别再踩）

1. **多进程僵尸占端口**：多次"重启"实际起了新进程，旧的还占着 17878（Windows 重复绑定），连接全被最老的接走——"改了不生效"的元凶。**重启前必须按命令行精确杀干净所有 python/pythonw 的 panel 进程**（netstat -ano 核对监听者）。
2. **wire 绑定中断**：见 4.4。
3. **GET/POST 路由错位**：新路由加错 HTTP 方法区（/api/hall、/api/speak 先后犯过两次）——加路由先确认前端用什么方法调。
4. **heredoc 转义**：bash heredoc → JSON → Python 多层转义，`\v` 会变垂直制表符、`\n` 会变真换行——写文件内容一律用 Write 工具或 chr() 构造，不手写转义。
5. **URL 目录错位**：preview_cache 的文件别用 /api/outputs/file 伺服（404）。
6. **缓存串别用固定版本号**：进程不重启它就不变，点刷新永远命中旧 JS。
7. **Edge DRM v2**：Sec-MS-GEC 已升级为变体 SHA256+CS64 双摘要（标准 SHA256 一律 403），算法移植自 edge-tts 开源库 `_edge_drm.py`。

## 九、FAQ

- **Q：免费能听到多少？** A：111 个全部可听。其中 MiMo 9 个支持自定义文字（需 MiMo Key，免费），其余 102 个播官方样音（零 Key）。
- **Q：为什么 Edge 浏览器音色被删了？** A：用户裁定浏览器音色不合需求（1.2.4），整体移除。算法移植保留在 `_edge_drm.py`……已随 1.2.4 删除，如需恢复参考 CHANGELOG 1.2.1 的实现说明。
- **Q：翻唱要花钱吗？** A：本地 Seed-VC 引擎免费（本机推理）；Kits.AI 订阅制。
- **Q：换机器怎么迁移？** A：拷 `D:\AI\声音工坊\` 整个目录 + 重装插件。
