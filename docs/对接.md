# 声来对接契约

> **一句话定位**：声来是「声音工作台」——把文字变成某个音色的语音，也能克隆音色、翻唱歌曲；对宿主的全部接口都在本机 `127.0.0.1:17878`，不需要云服务中转（合成时才调供应商）。

本文是给「不是海螺」的宿主 / 用户看的：怎么接、能接到什么、接错会怎样、坏了怎么查。
机器可读身份见仓库根 `metadata.json`；运行时探活见 `GET /api/health` 与 `GET /api/manifest`。

---

## 一、三种接法

### 1. HTTP 面板（最通用，推荐）

面板进程自己就是 HTTP 服务，绑定 `127.0.0.1`，**没有鉴权**（只在本机回环地址，不要映射到公网）。

```bash
python panel/server.py --port 17878   # 或 python panel/launch.py --no-browser
```

| 接口 | 方法 | 用途 |
|---|---|---|
| `/api/health` | GET | 探活：`{"ok":true,"id":"voice","version":"1.9.0","uptime_s":123}` |
| `/api/manifest` | GET | 身份与运行态：`metadata.json` 全文 + 实际端口 / pid / 启动时间 |
| `/api/status` | GET | 供应商配置状态、音色 / 产出数量、ffmpeg 是否可用（含本机数据路径，仅供本机用） |
| `/api/speak?text=…&voice=…` | GET | **最简合成**：直接返回音频字节（wav/mp3），`&json=1` 改为返回文件信息 |
| `/api/speak/voices` | GET | 可用音色列表（名称 / 供应商 / 模型 / 当前音色） |
| `/api/tts` | POST | 结构化合成：text / voice_name / format / rate / pitch / volume / emotion / mood |
| `/api/config` | GET / POST | 读写供应商配置（Key 读取时打码，写入后立即校验） |
| `/api/material-voices`、`/api/materials` | GET | 素材库 |
| `/api/outputs`、`/api/outputs/file?name=…` | GET | 产出列表与音频文件（支持 `Range`） |
| `/api/preview`、`/api/quick-clone`、`/api/kits/sing`、`/api/kits/convert` 等 | POST | 试听 / 快速克隆 / 翻唱 / 换声（详见源码路由） |

`/api/health` 与 `/api/manifest` 只读、无副作用，不含任何 Key、用户名或本机路径，可放心给外部监控轮询。

### 2. MCP / 函数级调用

- **MCP（stdio）**：`mcp/server.py`，JSON-RPC 2.0，一行一条消息，16 个工具：
  `voice_status`、`voice_provider_setup`、`voice_material_add`、`voice_enroll`、
  `voice_quick_clone`、`voice_register_manual`、`voice_catalog`、`voice_design`、
  `voice_material_generate`、`voice_mimo_tts`、`voice_clone_universal`、`voice_convert`、
  `voice_sing`、`voice_tts`、`voice_library`、`voice_panel`。
  宿主 MCP 配置示例（`<插件根>` 换成实际路径）：

  ```json
  {"mcpServers": {"voice-studio": {"command": "python", "args": ["<插件根>/mcp/server.py"]}}}
  ```

- **函数级**：不起任何服务，直接 `import lib.flows` 调 `flows.synthesize(text, voice_name, opts)`、
  `flows.quick_clone(...)`、`flows.sing_cover(...)` 等；返回 dict 里带 `path` / `file` / `size`。
  需要先 `sys.path.insert(0, 插件根目录)`，并保证数据根目录可写（见「单独运行」）。

### 3. 事件

声来**不监听宿主事件，也不提供 webhook**。它只有一个出站动作：合成 / 换声 / 翻唱成功后，
`lib/ring_ingest.notify()` 往「环形的心」MCP 写一条留痕（fire-and-forget，失败只打 stderr，不影响主流程）。
宿主若想看「又出了什么新音频」，正确做法是轮询 `/api/outputs` 或 `voice_library(section="outputs")`，
不要依赖回调。

## 二、能力清单

- **克隆音色**：一句话快速克隆（≥10 秒干净人声，可保留或即用即弃）、素材入库后正式注册、跨平台复刻。
- **合成语音**：已登记音色 → wav/mp3；语速 / 音调 / 音量 / 情绪（开心、温柔、生气…）/ `mood=tide` 心情联动。
- **AI 声音设计**：一句文字描述直接生成音色（需百炼 Workspace，走 cosyvoice-v3/v3.5）。
- **翻唱 / 换声**：歌曲 → 人声分离 → 换声 → 混回伴奏；引擎可选 Kits.AI（云端，付费）或本机 Seed-VC（免费）。
- **供应商**：百炼、小米 MiMo、硅基流动、ElevenLabs、Fish Audio、Kits.AI、MiniMax，以及任意 OpenAI 风格
  自定义 TTS（`custom:<id>` 模板）。能力（catalog / enroll / tts…）由适配器声明，接入新供应商界面零改动。
- **素材与产出**：按音色名分目录的素材库、合成产出索引、试听缓存、用量记账。
- **面板**：`panel/www` vanillajs 单页，任务流工作台；`/api/shutdown`（POST）可关停。

## 三、失败语义

统一约定：HTTP 接口失败返回 **JSON `{"error": "可读中文"}`**，供应商 / 参数类错误 **400**，
未知路由 **404**，未预期异常 **500**（`{"error":"TypeError: …"}`）。MCP 侧业务错误不抛协议错误，
而是 `result.isError = true` + `content[0].text = "出错: …"`，宿主照常展示即可。

| 场景 | 返回 | 说明 |
|---|---|---|
| 没配模型 / Key 为空 | 400，`error` 说明缺哪个供应商的哪一项 | 例如「百炼 缺少配置项「API Key（sk- 开头）」…」；不会静默退回默认模型 |
| 音色未注册 | 400，`音色「x」未注册…` | 先用 `/api/speak/voices` 或面板登记 |
| 网络不可达 / 连接被重置 | 400，`无法连接 <url>` | 底层对瞬时网络错误自动重试 2 次（1.5s / 3s 退避） |
| 供应商任务超时 | 400，`<任务>等待超时（Ns），当前状态: …` | 音色注册默认 120s；翻唱/分离任务更长，客户端超时请设 ≥5 分钟 |
| 音频格式不支持 | 400，明确列出支持格式 | 克隆参考音频只收 mp3/wav；换声收 wav/mp3/flac；翻唱收 wav/mp3/flac/webm（≤50MB） |
| 音频过大 | 400，`参考音频太大（base64 后需 ≤10MB）…` | 建议剪到 30 秒内 |
| 文本为空 | 400，`text 不能为空` / `合成文本不能为空` | — |
| 供应商 HTTP 业务错误 | 400，`HTTP <code> 来自 <url>` + 响应前 600 字 | 上游报错原样带回，便于排障 |

面板本身没有全局请求超时，长任务（翻唱、批量注册）会在请求里一直等；调用方必须自己设超时。

## 四、单独运行（不装海螺 / 不用任何插件宿主）

可以。声来没有任何宿主强依赖，**纯标准库**，一个 Python 就能跑：

1. 装 Python 3.9+（Windows 上 `python --version` 能出来即可）。
2. 在插件根目录执行 `python panel/server.py --port 17878`
   （想无窗口后台跑并用浏览器打开：`python panel/launch.py`；关闭：页面右上角 ⏻ 或 `python panel/launch.py --stop`）。
3. 打开 <http://127.0.0.1:17878/>，在「设置 → 模型接入」填一个供应商 Key（小米 MiMo 目前免费即可起步）。
4. 造 / 挑一个音色后，`/api/speak` 就能出语音。

需要什么：

- **必需**：Python 3.9+；一个 TTS 供应商的 API Key（或本机 Seed-VC 做换声/翻唱，可零 Key）。
- **可选**：`ffmpeg`（mp3 混音、格式转换；没有时 wav 仍可混）、本机 Seed-VC + demucs（免费翻唱）。
- **数据目录**：默认 `~/.voice-studio`（Windows 有 `D:\AI` 时为 `D:\AI\声音工坊`），可用环境变量
  `VOICE_STUDIO_HOME` 覆盖；`config.json` 里存 Key，只落本机磁盘，不会进对话。
- **端口**：默认 17878，被占用时自动 +1 试到 17879…（最多 50 次）；实际端口写进数据目录的 `.panel.json`，
  `/api/manifest` 的 `runtime.port` 也永远是真实值。
- 若 17878/17879 已有面板在跑，`panel/server.py` 会直接退出（防僵尸进程）；先复用已有实例。

## 五、自检（curl）

```bash
# 1. 探活：应返回 200 + 合法 JSON，id=voice，version 与 lib/config.py 一致
curl -s http://127.0.0.1:17878/api/health

# 2. 身份清单：metadata 全文 + 真实端口 / pid / ISO 启动时间
curl -s http://127.0.0.1:17878/api/manifest

# 3. 供应商与音色概况（含本机路径与本机配置状态）
curl -s http://127.0.0.1:17878/api/status

# 4. 有没有可用音色
curl -s http://127.0.0.1:17878/api/speak/voices

# 5. 真合成一句（返回音频字节；加 &json=1 看文件信息）
curl -s "http://127.0.0.1:17878/api/speak?text=%E4%BD%A0%E5%A5%BD&voice=%E6%B5%8B%E8%AF%95%E5%BE%A1%E5%A7%90&json=1"
```

Windows PowerShell 里用 `curl.exe`（`curl` 可能是 `Invoke-WebRequest` 的别名）。
判断「接得对不对」只看两条：`/api/health` 的 `ok` 为 `true` 且 `id` 与 `metadata.json` 一致；
`/api/manifest` 的 `runtime.port` 与你实际访问的端口一致。
