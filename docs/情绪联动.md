# 声来 × 情绪插件 · 对接指南

> 让角色说话带情绪：**情绪插件只需要提供一个词**，声来负责把它变成声音的波动。

---

## 声来侧已就绪的接口

| 入口 | 用法 | 适合谁 |
|---|---|---|
| **HTTP** | `GET /api/speak?voice=音色&text=文字&emotion=生气` | 任何框架/插件：QQ 机器人、AstrBot、自建服务——拉取即发 |
| **MCP** | `voice_tts(text=…, voice_name=…, emotion=生气)` | ZCode 里的 AI：自己决定这句话用什么情绪说 |
| **面板** | 大厅「情绪」下拉 → 合成正式版 | 人手动试 |

**支持的 9 种情绪**：开心 / 兴奋 / 温柔 / 生气 / 委屈 / 难过 / 撒娇 / 困倦 / 得意
（未知情绪自动跳过不报错——情绪插件随便传都不会炸）

---

## 情绪怎么变成声音

| 情绪 | 语速 | 音调 | 音量 | MiMo 音色额外语气 |
|---|---|---|---|---|
| 开心 | ×1.08 | ×1.08 | +5 | 语气欢快活泼，带着笑意 |
| 兴奋 | ×1.15 | ×1.12 | +10 | 语气兴奋激动，能量拉满 |
| 温柔 | ×0.95 | ×1.06 | 0 | 语气温柔轻软，慢慢说 |
| 生气 | ×1.12 | ×0.93 | +15 | 语气生气，硬邦邦的 |
| 委屈 | ×0.92 | ×1.05 | -5 | 语气委屈，带点哭腔 |
| 难过 | ×0.88 | ×0.94 | -12 | 语气低落难过，有气无力 |
| 撒娇 | ×1.05 | ×1.12 | 0 | 语气撒娇拖长音，黏黏的 |
| 困倦 | ×0.85 | ×0.96 | -10 | 语气困倦，半梦半醒 |
| 得意 | ×1.02 | ×1.06 | +8 | 语气得意，扬眉吐气 |

MiMo 音色（如「小鲸鱼」）在参数波动之外还有**原生语气演绎**，效果最明显；其它平台音色靠参数波动。

## 情绪插件侧怎么接（三种典型形态）

### ① 插件自己算出情绪 → 传给声来

情绪插件维护角色的当前心情（规则/LLM 判断都行），在调用语音时把情绪词附上：

```python
# 伪代码：情绪插件里
mood = 情绪插件.当前情绪()            # 如 "开心"
audio = requests.get(f"{声来}/api/speak", params={
    "voice": "小鲸鱼", "text": reply, "emotion": mood,
})
```

### ② AI 自己选情绪（推荐，最自然）

角色本来就是 LLM——把 `voice_tts` 工具的 `emotion` 参数写进人设提示词，让 AI **每句话说这句话时自己标注情绪**：

```
说话时根据内容给 voice_tts 传 emotion：
讲笑话/夸人 → 开心；被怼 → 生气；安慰人 → 温柔；要钱 → 撒娇……
```

无需任何情绪插件——模型自己就是最好的情绪引擎。

### ③ 情绪插件 → AI → 声来（串联）

情绪插件把心情注入 AI 的上下文（如「【当前情绪：开心】」），AI 说话时调 `voice_tts(emotion=…)` 保持一致。

---

## 注意

- 情绪只在**合成时**生效——同一个音色，同一句话，不同情绪合成出的音频不同
- MiMo 限时免费：情绪合成的成本随 MiMo 走（现价 0）
- 想加新情绪：`lib/flows.py` 的 `EMOTION_PRESETS` 加一行即可
