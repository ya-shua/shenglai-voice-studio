## 一、声来侧：对外语音接口（v1.7.0 起可用）

| 接口 | 说明 |
|---|---|
| `GET /api/speak?voice=音色名&text=文字&rate=1.0` | 直接返回音频字节（wav/mp3），框架拉取即发 |
| `GET /api/speak?…&emotion=生气` | **情绪联动**：开心/兴奋/温柔/生气/委屈/难过/撒娇/困倦/得意——声来折算成语速/音调/音量，MiMo 音色还会带原生语气词。情绪插件只管传当前心情一个词 |
| `GET /api/speak?…&json=1` | 返回 JSON（file/url），框架自己拉音频时用 |
| `GET /api/speak/voices` | 可用音色列表（名称/来源/模型/当前音色） |

### 用哪个 Key（对应关系）

| 动作 | 用的 Key |
|---|---|
| 大厅试听 | 免费，零 Key（官方样音）/ MiMo Key（免费合成） |
| 登记的音色发语音（/api/speak） | **该音色所属模型的 Key**——MiMo 音色用 MiMo Key（免费），百炼音色用百炼 Key（几厘钱/句），卡片的来源标注写着归属 |
| 一句话造音色（描述生成） | 小米 MiMo Key（限时免费） |
| 音频克隆 | 取决于克隆来源：百炼 Key / 硅基 Key / MiniMax Key |
| 翻唱（本地 Seed-VC） | **不需要 Key**（本机推理）；Kits.AI 路线用订阅 |

- 音色必须是声来里已登记的（免费音色大厅挑的、造的、克隆的都行）
- 未接入对应模型时返回 400 + 引导信息；Key 失效时返回一句人话指引

## 二、qq-bridge 侧：qq_speak 语音工具（主链路，已启用）

适配器在 qq-bridge 仓库（`D:\我的电脑\文档\deepseek-harness\default-workspace\qq-bridge`）：
- `src/shenglai-voice.js`（合成客户端）+ `src/bridge.js` 的 `/api/socialV2/speak-voice` 路由 + `src/mcp-snowluma-safe.js` 的 `qq_speak` / `qq_speak_voices` 工具
- 配置：`config.json` → `socialV2.voice.shenglai`（全局默认「测试御姐」）+ `tools.speakVoice: true`
- **音色跟角色走**：`shenglai.roleVoices` 角色绑定（`"女儿模式": "小鲸鱼"`），解析顺序 显式指定 > 角色绑定 > 全局默认；当前女儿模式绑定了 MiMo 免费造的「小鲸鱼」音色
- 详细说明：qq-bridge `docs/声来语音.md`

## 三、AstrBot 侧：语音输出适配器（备选，未部署）

位置：环形的心仓库 `integrations/shenglai-voice/`（照 `integrations/astrbot` 的模式）

**装法**：把 `integrations/shenglai-voice/` 整个丢进云端 AstrBot 插件目录
`<AstrBot>/data/plugins/astrbot_plugin_shenglai_voice/`，WebUI 启用即可。

行为：
- 每条 AI 文字回复自动跟一条语音（Record 组件，NapCat 转 QQ 语音）
- `/voice_on` `/voice_off` 会话级开关
- 长回复（>500 字）自动跳过；合成失败文字照发

注意：云端 AstrBot 访问不到本机声来，需先建 SSH 反向隧道（`ssh -R 17878:127.0.0.1:17878 …`）。

## 四、前置条件

1. 声来面板在跑：`http://127.0.0.1:17878`（桌面「声来」双击，或 ZCode `/voice:panel`）

3. 主链路（qq-bridge）：qq-bridge 在跑 + `voice.enabled`/`tools.speakVoice` 已开
4. 备选（AstrBot）：AstrBot 本身在跑 + NapCat 等适配器正常 + SSH 反向隧道已建
