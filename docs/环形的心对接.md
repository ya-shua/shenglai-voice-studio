# 声来 ⇄ 环形的心 对接说明

> 声来负责「怎么说」，环心负责「记得住」。
> 对接只靠一个 HTTP 接口 + 一个 AstrBot 适配器，两边本体都不用改。

---

## 链路

```
用户消息 ──► AstrBot ──► 她的文字回复
                              │
                              ▼
              声来 /api/speak（音色 + 文字）
                              │
                              ▼
              音频文件 ──► Record 组件 ──► QQ 语音跟一条
```

---

## 一、声来侧：对外语音接口（1.6.0 起内置）

| 接口 | 说明 |
|---|---|
| `GET /api/speak?voice=音色名&text=文字&rate=1.0` | 直接返回音频字节（wav/mp3），框架拉取即发 |
| `GET /api/speak?…&json=1` | 返回 JSON（file/url），框架自己拉音频时用 |
| `GET /api/speak/voices` | 可用音色列表（名称/来源/模型） |

- 音色必须是声来里已登记的（免费音色大厅挑的、造的、克隆的都行）
- 未接入对应模型时返回 400 + 引导信息

---

## 二、环形的心侧：AstrBot 语音输出适配器

位置：本仓库 `integrations/shenglai-voice/`（照 `integrations/astrbot` 的模式）

**装法**：把 `integrations/shenglai-voice/` 整个丢进 AstrBot 插件目录
`<AstrBot>/data/plugins/astrbot_plugin_shenglai_voice/`，WebUI 启用即可。

行为：
- 每条 AI 文字回复自动跟一条语音（Record 组件，NapCat 转 QQ 语音）
- `/voice_on` `/voice_off` 会话级开关
- 长回复（>500 字）自动跳过；合成失败文字照发

---

## 三、前置条件

1. 声来面板在跑：`http://127.0.0.1:17878`（桌面「声来」双击，或 ZCode `/voice:panel`）
2. 至少登记了一个音色（大厅挑 / 造声音做 / 克隆）
3. AstrBot 语音输出：还需 AstrBot 本身在跑 + NapCat 等适配器正常
